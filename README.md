# Student Result Manager

A simple command-line Python application for managing student marks and checking pass/fail results.

## Features

- Add a student and their marks
- View all stored students
- Check whether a student passed or failed
- Simple menu-driven command-line interface

## Requirements

- Python 3

## Run the project

```bash
python3 "student result manager/student_result_manager.py"
```

## Result rule

A student passes with marks of **40 or higher**; otherwise the result is **Fail**.
